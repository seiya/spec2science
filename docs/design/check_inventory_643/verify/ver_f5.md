On those paths the IR hash is bound in the selected Validate's key, and that Validate was authored by a conductor run, so its IR passed the gate of THAT run. For the per-case copies (PE-043/058/066/067) that second fact is NOT established: at readiness (`cross_target_only=True`) they act only on cross-target predicates, which the verdict author leaves as `no_comparand` placeholders before the loop; whether `_shape_state_agreement` ran them at the certifying Validate was not verified. So F1 should be restated as "on every path that authors a verdict or certifies a phase of the node being run", with the dependency-readiness path named as outside it.
